# Archived Python options prototype

`python-backend/` preserves the pre-Rust Python implementation, requirements, tests, and original technical documentation. It is not part of the active backend, container build, API, or Rust test suite.

The archived code models options, Black–Scholes pricing, and Greeks. Those concepts are intentionally absent from the active outcome-share application. Read the archive only for historical comparison or migration review; do not copy its API or accounting assumptions into v2.
